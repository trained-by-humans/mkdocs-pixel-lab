# Pixel Lab

A retro-inspired theme for MkDocs, with pixel borders, bold colors, and
arcade-style shadows. This website uses Pixel Lab's default appearance: what
you see here is what you start with.

[Get started](getting-started.md) · [Explore components](components/index.md) ·
[View on GitHub](https://github.com/trained-by-humans/mkdocs-pixel-lab)

## Start with your site

Install the theme and select it in `mkdocs.yml`:

```bash
python -m pip install mkdocs-pixel-lab
```

```yaml
theme:
  name: pixel-lab
```

Already using MkDocs? Keep your Markdown and navigation. Follow
[Get started](getting-started.md) to switch themes and enable the content
features you need.

## Set up your theme, then build your pages

Start with [Theme setup](setup/index.md) to configure your site's colors, fonts,
branding, navigation, search, and repository links once.

Then build your documentation one page at a time with [Components](components/index.md).
Each guide brings together a live example, its Markdown, required extensions,
and appearance settings—even when those settings live under `theme` in
`mkdocs.yml`.

For example, [Content tabs](components/tabs.md) covers writing tabs, choosing
their layout, and changing selected-tab colors in one place.

## Built for documentation

- Responsive section navigation and a compact search panel.
- Repository, source, and edit links with configurable icons.
- Syntax-highlighted code with copy buttons.
- Alerts, tabs, collapsible notes, tables, and responsive media.
- Bundled Inter and IBM Plex Mono fonts, without external font requests.

See the [configuration reference](reference/configuration.md) for defaults and
[compatibility notes](reference/compatibility.md) for current boundaries.
